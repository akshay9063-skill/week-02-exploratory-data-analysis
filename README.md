## How to run
Install dependencies with `python -m pip install pandas numpy matplotlib`. Open the notebook in Jupyter or Google Colab. Keep the CSV in the same folder and run cells from top to bottom.

## Main findings
Petal length and width are strongly positively related. Petal measurements differ by species, while sepal measurements overlap more. These are descriptive findings and do not establish causation.
